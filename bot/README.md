# Автопост новостей через GitHub Actions

Workflow `MultiCraft news bot` раз в 10 минут проверяет сайт. Когда в «Что нового» появляется новая версия, он публикует её в `@tgkcoqoza` со ссылками на сайт, установщик и сборку. Это не интерактивный бот: команды он не принимает.

## Настройка

1. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
2. Имя: `MULTICRAFT_BOT_TOKEN`, значение — токен из BotFather.
3. Добавьте бота администратором в канал `@tgkcoqoza` с правом публикации.
4. Вкладка **Actions → MultiCraft news bot → Run workflow** — тестовый запуск.

При первом запуске `bot/state.json` уже содержит `1.28.5`, поэтому старую новость он не опубликует. Дальше версия сравнивается с сайтом; при изменении бот публикует сообщение и коммитит новый `state.json`.

## Ограничения

- Cron в GitHub Actions может задерживаться на 5–20 минут.
- В публичных репозиториях расписание могут отключить после 60 дней без активности — тогда запустите workflow вручную или сделайте коммит.
- Токен хранится только в Secrets; `config.json` и токены в репозиторий не коммитить.

## 24/7 на GitHub Actions

В репозитории есть workflow .github/workflows/bot.yml:
- сессия бота длится 5 ч 45 мин, затем workflow сам запускает следующую через workflow_dispatch;
- каждые 6 часов есть резервный запуск по расписанию;
- одновременно работает только одна сессия (concurrency), поэтому Telegram не получает конфликт getUpdates.

Настройка:
- секрет MULTICRAFT_BOT_TOKEN — токен бота;
- переменная MULTICRAFT_ADMINS — ID администраторов через запятую.

Ограничения GitHub Actions:
- задание не может длиться больше 6 часов, поэтому это не гарантированные 24/7: между сессиями возможны короткие паузы;
- сообщения, отправленные в паузе, пропускаются (бот начинает с последнего обновления);
- при простое репозитория 60 дней GitHub может отключить расписание;
- для гарантированного 24/7 нужен VPS или постоянно включённый ПК.
