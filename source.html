Установка за три шага

Скачивание, установка и первый запуск занимают меньше времени, чем настройка одного модпака вручную.

Кнопка выше или ссылка вверху страницы. Нужен Windows 10/11 x64, около 300 МБ на диске под лаунчер и Java.

Запустите и войдите

Установщик создаст ярлыки. При первом старте лаунчер поставит Java и предложит ник или вход Microsoft — без пароля тоже можно.

Файлы версии и перф-моды скачаются один раз. Дальше — кнопка «Играть»; HUD 1.7.1 ставится сам для 1.21.4.

Частые вопросы

Честно о том, что может смутить.

Почему Windows предупреждает при запуске?

У установщика нет платной цифровой подписи, поэтому SmartScreen показывает общее предупреждение. Сверьте SHA-256 с указанным на этой странице: если хеш совпал, файл не изменён.

Нужно ли ставить Java отдельно?

Нет. Лаунчер скачает рантайм Mojang под нужную версию и будет использовать его. Вручную путь задаётся в настройках, если у вас уже есть своя Java.

Где хранятся миры и настройки?

В %APPDATA%\.multicraft. При обновлении на новую версию папка не удаляется: миры, конфиги HUD и скины остаются на месте.

Это официальный лаунчер Minecraft?

Нет, это сторонний лаунчер. Он не связан с Mojang или Microsoft; Minecraft — товарный знак Mojang Synergies AB. Для входа нужен купленный аккаунт, если вы играете по лицензии.

Как обновиться на новую версию?

Скачайте новый установщик и поставьте поверх: ярлыки заменятся, а данные в профиле сохранятся. Лаунчер сам обновит HUD и перф-моды при следующем запуске игры.

Готовы играть?

Установщик, Java и перф-моды — один клик. Дальше только выбор версии и кнопка «Играть».
